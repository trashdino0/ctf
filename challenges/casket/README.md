# Casket

**Category:** Reverse / Java  
**Difficulty:** Hard  
**Points:** 500

> A sealed Java archive was recovered from an old build server. Every failed
> license attempt prints the same short error, but the checker is buried behind
> several layers of encrypted classes. Find the license key and make the
> archive reveal the flag.
